Desktop Auto-Click Bot

Automate pixel-perfect mouse interactions, timing loops, and conditional click sequences to clear repetitive desktop work with confidence.

Overview

This downloadable automation script delivers a reliable auto-click engine built with Python and PyAutoGUI. Configure click coordinates, delays, loop counts, and keyboard interrupts in a clean, commented YAML file. Real-time console logging and optional desktop overlay keep you informed while the bot runs.

Features

  • Multi-step click sequences with custom timing per step
  • Hotkey pause/stop controls for safe manual overrides
  • Region targeting and pixel color checks before click execution
  • Session logging and run summaries for compliance or QA review

Requirements

  • Windows or macOS workstation
  • Python 3.9+
  • PyAutoGUI, PyYAML (included in setup script)

Setup Steps

  1. Unzip the download and open a terminal in the project folder.
  2. Run python -m venv .venv && source .venv/bin/activate (or .venv\\Scripts\\activate on Windows).
  3. Install dependencies with pip install -r requirements.txt.
  4. Edit config.yml with your click coordinates, timers, and hotkeys.
  5. Launch with python run.py and monitor the console dashboard.
