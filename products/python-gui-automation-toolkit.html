Python GUI Automation Toolkit

A modular automation launcher featuring a polished desktop UI, macro recorder, and live run analytics.

Overview

This toolkit streamlines repetitive desktop operations through a curated set of Python modules. Launch tasks from a sleek Electron-style interface, configure macros with drag-and-drop blocks, and monitor execution stats in real time. Built on PySide6, PyAutoGUI, and FastAPI for optional remote triggers.

Features

  • Macro builder with conditional steps, loops, and error handlers
  • Integrated scheduler for recurring jobs and hotkey triggers
  • Live dashboard with throughput metrics and run history
  • Plugin architecture for adding custom modules or API calls

Requirements

  • Windows 10+ or macOS 12+
  • Python 3.10+
  • Node.js 16+ (optional, for building the desktop shell)

Setup Steps

  1. Create a virtual environment and install Python dependencies via pip install -r requirements.txt.
  2. Run python manage.py init to generate local config and encryption keys.
  3. Optionally install UI shell packages with npm install and build via npm run build.
  4. Configure macros in playbooks/ and assign to hotkeys inside the UI.
  5. Start the toolkit with python manage.py launch.

What's Included

  • GUI automation app source code
  • Macro templates and sample playbooks
  • UI theme files with dark/light variants
  • Implementation guide with scaling recommendations
