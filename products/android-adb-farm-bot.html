Android ADB Farm Bot

Automate fleets of Android devices with synchronized task rotations, data capture, and smart cooldowns.

Overview

This ADB-powered automation suite controls multiple connected Android devices from one dashboard. Schedule task waves, send scripted tap/swipe commands, collect screenshots, and log performance results. Designed for game farming, QA labs, and marketing teams managing multi-account workflows.

Features

  • Device manager with auto-discovery and connectivity health checks
  • Task queue with randomized offsets to mimic human behavior
  • Screenshot capture, OCR hooks, and CSV reporting
  • Command presets for taps, swipes, text input, and app restarts

Requirements

  • Windows, macOS, or Linux workstation with ADB installed
  • Python 3.10+
  • Connected Android devices with USB debugging enabled

Setup Steps

  1. Install Android Platform Tools and ensure adb devices lists your phones/tablets.
  2. Clone/unzip the project and create a virtual environment.
  3. Install requirements using pip install -r requirements.txt.
  4. Populate devices.yml with device aliases and target apps.
  5. Launch python manager.py to open the control console.

What's Included

  • ADB farm bot source code
  • Device manager GUI and CLI launchers
  • Sample task templates and rotation schedules
  • Documentation covering scaling tips and troubleshooting
