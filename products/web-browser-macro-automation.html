Web Browser Macro Automation Script

Replay optimized web journeys with dynamic form filling, conditional branching, and graceful recovery.

Overview

This Selenium-powered automation script records and replays browser actions with environment-aware logic. Inject runtime variables, handle multi-step verifications, and run in headless or full-browser mode. Perfect for QA teams, marketing ops, and data capture workflows.

Features

  • Macro builder using YAML scenarios and reusable component blocks
  • Error handling with auto-retry, alert screenshots, and Slack notifications
  • Support for Chrome, Edge, and Firefox with driver management included
  • CLI and scheduler integration for cron or CI/CD usage

Requirements

  • Python 3.9+
  • Latest ChromeDriver, GeckoDriver, or EdgeDriver
  • Network access for target web applications

Setup Steps

  1. Install dependencies via pip install -r requirements.txt.
  2. Set driver paths in .env or allow auto-download on first run.
  3. Create scenarios in scenarios/ using provided examples.
  4. Run python automate.py --scenario onboarding (or similar) to launch.
  5. Review logs and screenshot artifacts in the reports/ folder.

What's Included

  • Browser macro automation source code
  • Scenario templates for onboarding, data capture, and QA flows
  • Notification hooks for Slack/Teams email alerts
  • Comprehensive documentation and troubleshooting guide
